## 관찰 항목 (각 결과마다 체크)

- **마스크 번짐**: agnostic mask 가 의류 영역을 넘거나 못 덮음 (팔/목/허리 경계)
- **로고/프린트 드리프트**: 그래픽·텍스트가 뭉개지거나 위치 이동
- **경계 아티팩트**: 목선/소매/밑단의 이음새 부자연
- **색/질감 왜곡**: 원단 색상 시프트, 패턴 스케일 변화
- **체형 왜곡**: 사람 실루엣이 원본과 달라짐
